LITHIDE — SOURCES DU PALADIN

source/ : trois GLB immuables fournis par l'utilisateur, hashes et provenance.
v1-meshy-turnaround/ : images préparées pour Meshy (intentions artistiques).
v2-meshy-inspection/ : inspection du modèle et du rig ; assemblage initial rejeté.
v3-equipment-grips/ : prise équipée corrigée, marteau orienté avant/arrière.
v4-locomotion/ : marche et course en sprites entiers, scènes Godot et reproduction.
v5-reactions/ : dégâts et chute/mort, quatre directions, accessoires lâchés en3D.
v6-forward-fall/ : correction de la mort, genoux puis torse au sol comme le Vulpin.
  Cette version remplace la chute latéralev5 ; dégâts et locomotion conservés.

Le GLB réel et ses textures font autorité. Les originaux ne sont pas utilisés
directement dans le jeu. docs/.gdignore exclut toutes ces sources de l'export.
Voir v4-locomotion/README.txt pour refaire les images et contrôler les contacts.
