OCULIN - PACK MESHY

Quatre PNG transparents du meme personnage en pose neutre :

01-front.png : face, image principale.
02-left.png : profil gauche, personnage tourne vers la gauche de l'image.
03-back.png : dos.
04-right.png : profil droit, personnage tourne vers la droite de l'image.

Importer les images separement dans les emplacements correspondants du mode
Multi-View de Meshy. La face reste l'image principale. Ce pack ne contient
pas d'accessoire a generer separement : collier, medaillon et tenue font
partie du personnage. Aucun outil ou arme tenu en main.

Conseils officiels consultes le2novembre2026 :
https://help.meshy.ai/en/articles/16102789-meshy-multi-view-best-practices-angles-and-images
https://help.meshy.ai/en/articles/12634481-how-to-use-multi-view

Images generees avec ImageGen a partir du concept B choisi par l'utilisateur.
Elles servent de references illustrees ; elles ne sont pas les captures
calibrees d'un modele3D. Verifier le modele reconstruit avant rigging,
notamment l'oeil unique, les mains, les pieds et la collerette.
