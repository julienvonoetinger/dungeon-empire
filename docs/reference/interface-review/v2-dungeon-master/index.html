A / RECOMMANDATION

La main sur le donjon.

Une palette basse, stable, avec vos outils usuels. Le violet signale une action ; le métal reste sombre.

À ESSAYER

  1. Choisissez Pointes.
  2. Touchez plusieurs cases libres.
  3. Corrigez avec Annuler.

Glisser sur le terrain déplace la vue. Le glisser-déposer depuis un outil fonctionne aussi, avec un aperçu au-dessus du doigt.

3 poses : 6 → 3 actionsUne fois l’outil sélectionné, plus de confirmation par case.

01 / GESTES

Poser sans recommencer.

L’outil reste actif. Une touche pose, un glissement déplace la vue. L’annulation rend l’expérimentation réversible.

02 / IDENTITÉ

Vous êtes le maître.

Fer noir, pierre, sceaux et accents magiques. L’or désigne la ressource, pas tout l’habillage.

03 / ENVIRONNEMENT

Creusé dans la roche.

Une masse minérale continue entoure les murs. Le sol jouable reste plus clair ; la brume se limite aux bords.

Étude visuelle et gestuelle, sans sauvegarde ni dépense dans le jeu. Décors et annulation sont des propositions à intégrer ; les coûts de décors restent à définir. Notes & limites
