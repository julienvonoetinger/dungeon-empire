# Chest v2

## Current runtime: v3 treasury tile

Dedicated tile artwork: `assets/mobile/treasury-floor-v1.png`, generated with
the built-in image tool using `floor-pavers-v4.png` as the color/material
reference. Prompt: square top-down opaque dungeon floor tile, neutral gray
stone, shallow central beveled chest plinth, scattered gold coins and three
small coin piles around its sides, bare outer stone border, no chest, no UI,
no perspective, no floating shadow. The sampler is mapped once per treasury
quad, but only gold-colored pixels and the central plinth are composited.
The original world-space paving and its joints remain continuous elsewhere.
The source plinth rectangle (0.235, 0.26)-(0.765, 0.67) is remapped to a
0.64-cell square centered at (0.5, 0.5), independently of the coin layer.
This removes its source-image offset and unequal width/depth under camera
quarter-turns; the billboard chest retains the same world-space anchor.
`treasury-floor-empty-v1.png` was generated by editing the full tile to remove
all coins while preserving the stone plinth and framing. UV2.y selects full
(1) or empty (2) from each vault's stored gold; zero gold removes ground coins
and refilling restores them. Texture import is capped at
512 pixels with mipmaps; no extra geometry or lights are added.

The current sprites are `assets/mobile/chest-full-v3.png` and
`assets/mobile/chest-empty-v3.png`. Built-in image editing removed only the
stone plinth from the full image, preserving camera, framing and chest;
then removed coins for the empty state. No external shadow or floor is baked
into these images. The floor renderer marks VAULT quads as treasury tiles
using UV2.y, with framed stone paving at the existing y=0.175 surface.
There is no overlay quad or raised platform. Tile dimensions and exposed
edge treatment remain shared with the neighboring floor. Both sprites retain
the footprint anchor and width below. Imports remain capped at 512 pixels.

## Previous version

Generated with the built-in image generation tool, using the approved mobile
dungeon mockup as the style reference. Runtime assets:

- `assets/mobile/chest-full-v2.png`
- `assets/mobile/chest-empty-v2.png`

Generation brief: one transparent isometric game sprite; compact dark wood
chest, broad matte iron bands, restrained antique brass hardware, readable
stylized dark fantasy forms. Open lid and modest gold contents. Chest flush
on a thin beveled neutral gray stone slab, slightly wider than the chest;
no feet, air gap, pedestal, external cast shadow, scene, or text.

Empty-state edit: remove only the coins and reveal the dark wooden interior;
preserve silhouette, framing, lid angle, stone base, materials and lighting.

The stone base is part of the artwork, not an additional floating shadow.
Both sprites share footprint anchor (49%, 67%) and canvas width 0.78 world
units. Imports use 512-pixel size limit and mipmaps. The store menu uses the
same full-chest art. `tools/android/configure-chests.gd` maintains import and
export selection. `tools/capture_chest.gd` captures both states at four camera
orientations with walls raised/lowered.
