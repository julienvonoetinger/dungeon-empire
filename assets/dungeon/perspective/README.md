# Maquette originale conservée

`reference-atlas.png` est l'illustration originale de l'utilisateur
(1672 × 941), copiée sans modification. Ce n'est pas un sprite rejeté.

Les anciens renderers qui y découpaient des éléments ont été retirés lors du
nettoyage du 23 octobre 2026. Aucune scène actuelle ne découpe cette image.

La référence active pour les matières stylisées est
`assets/dungeon/shared-materials/stylized-reference.png` et la recette active est
`assets/dungeon/shared-materials/active-recipe.json`.

Pour les règles de géométrie et d'export, suivre les documents actuels
`docs/reference/PAINTED_GODOT.md`, `WIREFRAME_WORKFLOW.md` et `MATERIAL_WORKFLOW.md`.
