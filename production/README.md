# Dungeon Master — Asset Production Pack

This package contains everything that can be prepared **without generating new images**.

It includes:
- the validated Batch 01 images already created;
- the complete asset folder structure;
- a master asset/state manifest;
- an image-generation queue with one task per image;
- a 10-at-a-time batch plan;
- Meshy/3D model planning;
- Godot state recommendations;
- canonical naming and art-direction constraints.

## Important
There are **no contact sheets to crop** and no fake PNG placeholders.
Missing images are listed in the manifests and must later be generated individually.
