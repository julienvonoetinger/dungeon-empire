# Controlled stone kit — 8 September 2026

Three Meshy image-to-3D jobs were generated through the manifest pipeline, using
`meshy-t2`, smart topology, PBR textures and a target of 6,000 polygons each:

| Canonical source under `production/meshy_assets` | Generated model under `assets/models` |
| --- | --- |
| `environment/modules/floor_tile_trap_match_1x1.png` | `environment/floor_tile_trap_match_1x1.glb` |
| `environment/modules/floor_tile_controlled.png` | `environment/floor_tile_controlled.glb` (superseded floor prototype) |
| `environment/modules/wall_straight_controlled.png` | `environment/wall_straight_controlled.glb` |

Godot extracts the embedded textures alongside each GLB. Keep those textures
and their import settings with the models. Generation task IDs and credit
information, where provided by Meshy, remain in the ignored `.meshy/tasks.json`.

## Runtime treatment

- The floor module spans exactly one logical cell and matches the traps' dark,
  constructed flagstone language. One MultiMesh applies coordinate-stable
  quarter turns to reduce repetition and covers only excavated cells. A dark
  backing remains beneath the relief to fill cracks and keep terrain closed.
- Relief lies between Y=0.035 and Y=0.175, around the existing floor Y=0.12.
  The base hides the bottom of the slab; props remain at their existing height.
- Consecutive wall faces are paired on the grid. Paired modules widen the
  stonework without increasing wall height or thickness. Single cells remain
  supported at turns and broken runs. Separate pillars are kept at corners.
- Cell signatures include wall pairing so excavation rebuilds affected neighbours.
- Stone uses the original Meshy textures. The floor's metallic response is
  disabled and roughness is 0.95 to retain a matte mineral appearance.

## Verification and captures

Run `tests/stone_relief_test.gd`, `tests/wall_span_test.gd` and the existing
floor, lighting and gameplay tests with Godot's `--headless --script` options.

Use `tools/capture_entrance.gd` for the starting-room comparison. Add
`-- --stone-corridor` for an elbow corridor that exercises odd-width runs.
`tools/capture_stone_kit.gd` produces a close-up of both generated assets.
Capture outputs are local, ignored files under `artifacts/`.

The Meshy HTTP client was also corrected to pass `timeout` by keyword to
`urlopen`; a regression test covers both submission and download bodies.
