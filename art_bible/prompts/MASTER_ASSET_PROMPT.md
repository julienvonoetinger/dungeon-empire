# Canonical Image Generation Prompt Framework

Use this framework only for generating **one asset at a time**.

## Base prompt

Create exactly ONE isolated game asset for the Dungeon Master project.

Art direction:
- stylized dark fantasy;
- supernatural, readable, stylized;
- polished low-poly 3D game asset;
- broad readable forms;
- hand-painted/PBR-inspired materials;
- anthracite/blue-gray dungeon stone where applicable;
- restrained violet/magenta supernatural emissive accents;
- warm gold/brass only where appropriate;
- no photorealism;
- no gore;
- no chibi;
- no generic red demon/lava aesthetic;
- no Dungeon Keeper imitation.

Presentation:
- one object only;
- full object visible;
- centered with margin on all sides;
- neutral 3/4 or isometric view;
- plain dark neutral studio background;
- no scenery;
- no text;
- no labels;
- no filename;
- no border;
- no grid;
- no contact sheet.

Asset instruction:
<INSERT EXACT ASSET INSTRUCTION>
