# Character Production Notes

Every character source image should:
- show one full-body character only;
- use a neutral readable pose suitable for image→3D;
- avoid action poses that hide limbs;
- avoid capes/weapons crossing the whole torso where possible;
- show hands and feet clearly;
- keep silhouette readable;
- use approximately 5–6-head stylized proportions;
- preserve species anatomy over class costume.

## Canonical hero targets

- `hero_vulpin_thief`: Vulpin + Thief; cape, daggers, loot bag.
- `hero_lithide_paladin`: Lithide + Paladin; living stone body, luminous seams/runes, large shield.
- `hero_batrafian_ranger`: Batrafian + Ranger/Scout; amphibian body, ranged weapon.
- `hero_mycean_mage`: Mycean + Mage; fungal silhouette, soft bioluminescence.
- `hero_nocturne_priest`: Nocturne + Priest; owl/bird-inspired scholar/spiritual silhouette.
- `hero_saurian_warrior`: Saurian + Warrior.
- `hero_forged_sapper`: Forged + Sapper; artificial body + structural demolition tools.
- `hero_human_barbarian`: Human + Barbarian; humans remain a minority.

## Insectoid restriction
No insectoid is currently canonical. Do not generate one unless the Art Bible is explicitly revised.
If reintroduced later, it must use arthropod head/mouth anatomy and **must not have a bird-like beak**.
